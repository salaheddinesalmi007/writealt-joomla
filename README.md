# WriteAlt for Joomla

Native Joomla administrator extension for generating accessible alt text and optimizing local article images.

## Latest release

Download [`pkg_writealt-1.0.15.zip`](./pkg_writealt-1.0.15.zip) and install it from **System -> Install -> Extensions** in Joomla.

The package includes the WriteAlt component and the native article integration plugin. The plugin is enabled automatically after installation.

## Requirements

- Joomla 5 or Joomla 6
- PHP 8.1 or later
- PHP cURL and GD extensions
- A WriteAlt API key

After installation, open **Components -> WriteAlt**, save the site API key, and refresh the images. Article images must be stored under Joomla's `/images` directory.
